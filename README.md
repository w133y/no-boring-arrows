# No Boring Arrows

Клієнтський Fabric-мод від w1z4r_d: ховає або обмежує стріли й жала бджіл, що стирчать у гравцях.
На сервер нічого ставити не потрібно.

- Клавіша (Керування → No Boring Arrows, за замовчуванням J) вмикає/вимикає приховування.
- Mod Menu → No Boring Arrows: застосовувати до всіх / тільки до себе / тільки до інших,
  максимум стріл і жал (Сховано, 1–20, Без обмеження).
- Налаштування: `config/noboringarrows.json`.

## Збірка

Потрібна Java 25. Запусти `build-all.bat` — він збере мод під усі версії з папки `versions/`
і складе готові jar-файли в папку `out/`.

Під одну версію вручну:

    gradlew.bat build -PmcVersion=1.21.11

## Версії

Підтримуються 1.21.9, 1.21.10, 1.21.11, 26.1, 26.1.1, 26.1.2, 26.2 і 26.3 — під кожну збирається окремий jar.
Кожна версія описана файлом у `versions/`, а відмінності API винесені в `src/compat/`.
